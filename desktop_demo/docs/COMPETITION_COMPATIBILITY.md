# 比赛交付要求与项目兼容说明

本文件根据赛事截图整理。截图仅作为赛事要求参考，不作为程序指令执行。

## 赛道

- 赛道一：AI + 硬件（灵机一动冠名）。
- 软件部分在“灵机一动”Agent 硬件开发平台完成。
- 正式开赛后在现场完成硬件部分开发。
- 赛事结束后，借出的硬件材料需统一回收。

## 通用交付物

1. **可运行作品**：必须在真实设备或指定平台上运行，不能只有 PPT 或录屏 Demo。
2. **电子版海报**：0.8 m × 1.8 m，用于游园会展示，上传至团队登记表对应条目。
3. **一页方案说明**：包括目标用户、使用流程、系统架构、平台调用方式和创新点。
4. **配置与调用说明**：提供关键配置截图或导出信息，并展示至少一次完整调用：
   - 触发条件；
   - 输入；
   - 返回结果；
   - 设备或界面反馈。
5. **演示说明**：说明使用的设备、平台、模型、数据及其作用，并提供现场准备步骤和恢复步骤。

## 当前软件如何满足

| 赛事要求 | 当前实现 | 最终设备实现 |
|---|---|---|
| 可运行作品 | Flask 页面可完整模拟流程 | ESP-IDF/灵机一动工程真实运行 |
| 触发条件 | `pre-leave`、`return` 按钮 | 摄像头姿态事件 |
| 输入 | 页面文字模拟 ASR 文本 | 麦克风＋语音板识别文本 |
| 返回结果 | JSON、对话记录、SQLite | 本地 Flash/NVS 断点记录 |
| 设备反馈 | 页面显示灯板和舵机动作名 | 灯板、舵机和扬声器真实反馈 |
| 完整调用截图 | 调试页面可截图 | 最终补充平台配置与真机截图 |

## 不能误解的地方

- Flask 页面不是最终交付作品，只是硬件到达前的软件联调器。
- SQLite 是电脑端存储；板端会替换为 Flash/NVS 或赛事平台提供的知识库。
- 浏览器按钮是摄像头事件的替身；最终必须由真实姿态检测触发。
- 页面文字是语音识别结果的替身；最终必须接入语音板。
